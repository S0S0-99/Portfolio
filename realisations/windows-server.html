Infrastructure Windows Server

Déploiement d'une infrastructure Windows Server complète en environnement virtualisé, incluant Active Directory, DNS/DHCP et déploiement de postes.

Contexte

Dans le cadre de mon BTS SIO option SISR, j'ai mis en place une infrastructure Windows Server complète en environnement virtualisé (VirtualBox), reproduisant l'architecture type d'un parc informatique d'entreprise, du contrôleur de domaine jusqu'au déploiement automatisé des postes clients.

Objectifs

  • Mettre en place un contrôleur de domaine avec Active Directory (AD DS)
  • Configurer les services réseau essentiels : DNS et DHCP
  • Automatiser le déploiement de postes clients via WDS
  • Structurer les utilisateurs et appliquer des stratégies de groupe (GPO)

Fonctionnement

Active Directory (AD DS)

  • Installation du rôle AD DS et promotion du serveur en contrôleur de domaine
  • Création d'unités d'organisation (UO) pour structurer utilisateurs et postes
  • Création des comptes utilisateurs et groupes de sécurité

DNS / DHCP

  • Configuration du serveur DNS pour la résolution de noms du domaine
  • Mise en place d'une étendue DHCP pour l'attribution automatique d'adresses IP

Déploiement de postes (WDS)

  • Configuration du rôle WDS pour le déploiement d'images Windows par le réseau (PXE)

Gestion des utilisateurs et GPO

  • Application de stratégies de groupe (GPO) pour homogénéiser la configuration des postes

Ce que ça m'a apporté

  • Une compréhension concrète du fonctionnement d'un domaine Active Directory
  • La configuration de bout en bout des services réseau d'un environnement Windows Server
  • La mise en place d'un déploiement de postes automatisé
  • Une bonne base pour administrer un parc informatique en environnement professionnel

Améliorations possibles

  • Ajouter un second contrôleur de domaine pour la redondance
  • Mettre en place une sauvegarde automatisée de l'annuaire AD
  • Documenter les GPO appliquées dans un tableau de suivi
