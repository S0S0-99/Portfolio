Script de monitoring automatisé en Python

Un script Python développé en stage pour surveiller automatiquement serveurs, sites web et API internes, avec alerte email en cas de panne.

Contexte

Dans le cadre de mon stage BTS SIO SISR, l'entreprise avait besoin d'un outil de surveillance simple pour être alertée automatiquement en cas de panne, sans dépendre d'une solution de monitoring payante ou complexe à déployer. J'ai développé un script Python répondant à ce besoin, exécuté quotidiennement via crontab sur un serveur Linux.

Objectifs du script

  • La disponibilité des sites web et applications internes utilisés au quotidien (HTTP 200 attendu)
  • La disponibilité des serveurs de domaine via un test de ping
  • La validité d'une API interne, en s'assurant qu'elle répond et renvoie des données

Dès qu'une anomalie est détectée, un email d'alerte est envoyé automatiquement aux personnes concernées via SMTP.

Fonctionnement

  • Une liste de sites/applications est parcourue avec le module requests ; le code HTTP de chaque réponse est analysé
  • Une liste de serveurs est testée avec un ping système (compatible Windows/Linux via platform)
  • Un appel à l'API interne vérifie qu'elle répond et que la réponse n'est pas vide
  • Chaque anomalie déclenche l'envoi d'un mail via smtplib
  • Le script tourne seul, planifié via crontab

Ce que ça m'a apporté

  • Les requêtes HTTP et la gestion des exceptions réseau
  • L'envoi d'emails automatisés en Python (SMTP, MIME)
  • L'exécution de commandes système multiplateforme
  • La consommation d'une API interne avec authentification
  • L'automatisation via crontab sous Linux

Le code

Le script ci-dessous a été anonymisé (noms de domaine, adresses email, identifiants et clés d'API réels remplacés par des valeurs génériques) afin de respecter la confidentialité de l'entreprise.

import urllib3
import requests
import smtplib
import subprocess
import platform

from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText

urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

username = "no_reply@entreprise.fr"
password = ""  

mail_to = [
    "responsable.it@entreprise.fr",
    "admin.reseau@entreprise.fr",
    "technicien@entreprise.fr"
]

smtp_server = "smtp.office365.com"
smtp_port = 587

api_url = "https://app.entreprise.fr"

api_headers = {
    "Authorization": ""  # clé API à ne jamais partager
}

sites = [
    "https://app1.entreprise.fr",
    "https://outil-metier1.entreprise.fr",
    "https://app2.entreprise.fr",
    "https://app3.entreprise.fr",
]

servers = ["SRV-01", "SRV-02"]

def send_mail(subject, body):
    msg = MIMEMultipart()
    msg["From"] = username
    msg["To"] = ", ".join(mail_to)
    msg["Subject"] = subject
    msg.attach(MIMEText(body, "plain"))
    try:
        server = smtplib.SMTP(smtp_server, smtp_port)
        server.starttls()
        server.login(username, password)
        server.sendmail(username, mail_to, msg.as_string())
        server.quit()
    except Exception as e:
        print("Erreur connexion email", e)

def ping_host(host):
    param = "-n" if platform.system().lower() == "windows" else "-c"
    command = ["ping", param, "1", host]
    try:
        result = subprocess.run(command, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        return result.returncode == 0
    except:
        return False
